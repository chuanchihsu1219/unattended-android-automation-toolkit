# Contributing

Small, test-backed pull requests are welcome.

1. Do not add APKs, credentials, personal data, production screenshots, or vendor-specific selectors.
2. Add or update tests for lifecycle, validation, persistence, or redaction behavior.
3. Keep Windows subprocesses bounded by timeouts and scoped to an explicit serial or PID.
4. Run `python -m pytest -q` before opening a pull request.
5. Explain the failure mode and acceptance check in the pull request description.
