# Security policy

## Supported version

Security fixes are applied to the latest commit on `main`.

## Reporting a vulnerability

Do not open a public issue containing credentials, personal data, proprietary UI dumps, screenshots, or exploit details. Use GitHub's private vulnerability reporting feature when available, or contact the repository owner through the public contact method on their GitHub profile.

Include the affected component, impact, reproduction conditions, and a redacted proof of concept. Remove tokens, account identifiers, absolute personal paths, and production data before sending evidence.

## Adapter boundary

This repository intentionally excludes production adapters. Keep target-specific selectors, authentication flows, screenshots, and captured data in a private repository unless you have permission to publish them.
